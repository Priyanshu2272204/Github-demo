# GitHub Demo

Welcome to my **GitHub Demo** repository! 👋

I created this repository to learn and practice **Git, GitHub, and GitHub Desktop**. It serves as a beginner-friendly playground where I can experiment with version control, manage repositories, and understand how developers collaborate on projects.

## 🎯 Purpose

The main goal of this repository is to:

- Learn the fundamentals of Git and GitHub.
- Understand how to create and manage repositories.
- Practice committing and pushing changes.
- Learn how to create and manage branches.
- Explore GitHub Desktop and its features.
- Get familiar with version control and collaboration workflows.

## 🛠️ Tools I'm Learning

- **Git** – Version control system.
- **GitHub** – Platform for hosting and managing Git repositories.
- **GitHub Desktop** – GUI application for managing Git repositories.
